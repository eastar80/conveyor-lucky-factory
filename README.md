# 행운 조립 공장

Web Crypto 기반의 균등 무작위 추첨 결과를 약 28초짜리 다중 생산라인 게임쇼로 보여주는 정적 웹앱입니다. 5개 라인의 분산·합류·재분산, 자동 카메라 팬/줌, 최종 후보 집중 연출과 Web Audio 효과음을 포함합니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 파일 서버로 이 폴더를 제공하세요.

## 공정성

참가자에게 속도나 능력치를 부여하지 않습니다. 추첨 시작 순간 `crypto.getRandomValues()`와 편향 제거 정수 샘플링을 사용한 Fisher–Yates 셔플로 당첨자를 먼저 확정합니다. 이후 애니메이션은 확정 결과를 시각적으로 공개하는 연출이며 이름, 입력 순서, 이름 길이는 당첨 확률에 영향을 주지 않습니다.
